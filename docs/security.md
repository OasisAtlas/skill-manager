# 数据与安全边界

- 安装器只复制本项目的 `SKILL.md`、`agents/`、`scripts/` 和 `templates/`。
- 完整初始化只修改 `${CODEX_HOME:-~/.codex}/AGENTS.md` 中由 `skill-manager` 标记管理的规则块。
- 第一次修改已有全局指令前创建固定备份 `AGENTS.md.skill-manager.bak`，不反复覆盖原始备份。
- 起止标记不完整时拒绝写入，交由用户检查。
- 分类信息不写进上游 Skill 包，避免污染或在升级时丢失。
- 创建别名时如目标路径已被无关内容占用，立即失败，不覆盖。
- 本项目不提升权限，不保存认证信息，也不接管 `skill-installer` 的来源安全判断。

安装第三方 Skill 仍等于信任其指令和附带资源；分类只改善组织方式，不代表安全审计或质量背书。
