# 行为规范

每次安装目标 Skill 时，必须遵守以下顺序：

1. 读取来源路径和目标 `SKILL.md`，确认正本名称、用途、流程、依赖和是否已安装。
2. 简要介绍主要能力、主要流程；只有影响安装或分类时才补充关键边界。
3. 读取已有类目并按实际能力匹配，不能只看名称关键词。
4. 在执行任何安装命令前取得明确分类决定。
5. 决定后才交给 `skill-installer` 下载正本。
6. 记录为已分类或未分类；分类时默认提出类目前缀别名，用户可拒绝。

## 分类询问规则

- 单一匹配：推荐该类目，同时允许改选、新建或不分类。
- 多个匹配：列出候选并询问选择哪个，同时允许新建或不分类。
- 无匹配：询问新建类目或不分类，不得静默创建。
- 用户提前给出类目：仍需复述准确类目并确认。
- 批量安装：逐项给出能力、流程和建议映射；整批或逐项确认前不安装任何一项。

## 不属于本项目的行为

- 普通使用一个已安装 Skill。
- 创建或修改 Skill，但没有安装外部包。
- 替代 `skill-installer` 的网络下载和认证逻辑。
- 自动把旧 Skill 按目录前缀重命名或迁移。
